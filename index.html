⚡ Le pipeline Graphify — DAG absolu

📁 Tes fichiers Docs, notes Obsidian, code, PDFs, vidéos — tout ce que tu as dans un dossier
↓ graphify lit tout
🔍 Extraction Claude lit chaque fichier et extrait les concepts clés (EXTRACTED) + devine les liens implicites (INFERRED)
↓ on structure
🕸️ Graphe de connaissances Chaque concept = un nœud. Chaque lien = une edge. Tout ça stocké dans graph.json
↓ algo de clustering
🌈 Communautés détectées L'algo regroupe les nœuds proches en clusters thématiques automatiquement
↙ graph.html ↓ graph.json ↘ GRAPH_REPORT.md
🎨 HTML interactif Tu vois ton graphe, tu cliques, tu navigues
🗃️ JSON structuré Interrogeable par Claude, MCP, agents IA
📝 Rapport texte Résumé lisible des clusters et connexions

➕ Comment enrichir ton graphify sans se tromper

1
Ajouter un fichier source
Pose ton fichier dans le dossier cible (ex: vault/2-CONCEPTS/), puis lance : /graphify --update. Graphify ne relit que ce qui est nouveau.
2
Ajouter une URL (article, repo GitHub)
/graphify add https://... — graphify fetch, extrait les concepts, les ajoute au graphe existant. Zéro risque de casser l'existant.
3
Vérifier avant de commit
Le fichier graph.json est la source de vérité. Avant d'enrichir, compte les nœuds (52 actuellement). Après enrichissement, vérifie que le nombre a augmenté.
4
Interroger après
/graphify query "nilpotence" — Claude traverse le graphe (BFS) et te sort tous les concepts liés. C'est là que la magie opère.
🚨 Le seul vrai risque
Ajouter du bruit (fichiers non curatés, copy-paste en vrac). Graphify extrait ce qu'il trouve — si tu mets du flou, tu crées des faux nœuds. Règle : un fichier = une idée claire.
